# Lords and Dragons on C

Учебный проект: компьютерная версия настольной 4X-стратегии
"Lords and Dragons" на языке C.

Главная цель проекта - подготовка к курсу "Операционные системы и язык C":
модульный C, работа с памятью, файлы, отладка, Git, позже сокеты и Raylib.

## Текущий статус

Проект находится на начальном этапе.

Сейчас есть:

- минимальная C-программа;
- сборка через Makefile;
- базовая документация по архитектуре;
- Git/GitHub-репозиторий.
