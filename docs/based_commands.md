# Типы юнитов и их обозначения

mech - мечник
kop  - копейщик
kon  - конница
luch - лучник

# Базовые команды для обработки ввода 

## Команда help

должна выводить текущие разрешенные команды

## Команда end turn

успешное окончание хода

## Команда move 

перемещает юнита с гекса на гекс
move <unit_id> <xy_hex_goto>

## Команда finish 

успешное завершение партии

## Команда status
    - показывает кол-во золота
    - показывает карту
    - исследованные и неисследованные гексы
    - где какой юнит находится 
    (их номера <тип><номер> + цвет)
    - текцщий игрок
    - текущий раунд

## Команда unit
    показывает текущее:
    - стоимость
    - скорость
    - здоровье
    - атака
    - защита
    - особенности

## Команда create

создает юнита
create <тип юнита>
